# Friendly workspace label

## Request

Change the default workspace display name to `My Workspace` for a more useful first-run experience.

## Approved steps

1. Update the default workspace definition in the setup module.
2. Use `My Workspace` as its visible label.
3. Keep existing saved workspace selections and labels unchanged.

## Validation

Use public APIs and real temporary files. Run the public suite.
