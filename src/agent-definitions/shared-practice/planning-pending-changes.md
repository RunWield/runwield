## Pending Changes During Planning

Inspect staged, unstaged, and relevant untracked changes before forming the Plan or Epic. Preserve all existing work.
Use task-relevant changes as evidence of the current state: distinguish what is already implemented from what remains.
Silently ignore unrelated changes in your conversation and planning artifacts. Do not include dirty-file inventories,
cleanup requests, or generic dirty-checkout warnings in a Plan. A dirty checkout alone is neither a blocker nor a risk.
If a concrete conflict actually prevents the requested work, explain that conflict and its effect on the task.
