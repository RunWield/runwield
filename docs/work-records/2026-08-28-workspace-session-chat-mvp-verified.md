# Workspace Session chat

## Summary

Workspace starts and continues Sessions through a shared chat shell with Runtime-owned configuration changes. Users can answer inline interactions, receive automatic availability updates, and use a slim Session top bar. Agent and model changes can be staged during active operations, while thinking changes depend on Runtime and model support.

## Future Planning Notes

Workspace is a Runtime consumer, not a second authority. Active-operation configuration staging must remain server-owned.
